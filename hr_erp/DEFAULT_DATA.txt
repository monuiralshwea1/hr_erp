============================================================================
 hr_erp — البيانات الافتراضية (Default Data)
============================================================================

1) هل تُنشأ البيانات الافتراضية عند تثبيت التطبيق؟
---------------------------------------------------
نعم. عند تثبيت التطبيق على أي سيرفر (بما فيه سيرفر ثانٍ) تُنشأ جميع
البيانات الافتراضية تلقائياً عبر دالة after_install الموجودة في:

        hr_erp/hr_erp/hrms_erp/install.py

ويتم تشغيلها تلقائياً بأمر التثبيت:

        cd /home/newsmart/frappe-bench2
        bench --site <اسم-الموقع> install-app hr_erp

وتنشئ:
  - DocType جديد: Employee Document
  - 7 حقول مخصصة (HR Settings / Employee / Employee Checkin)
  - 12 Number Card (بطاقات عدّ وجمع)
  - 9 Dashboard Charts (رسوم بيانية)
  - مساحة العمل "بوابة الموارد البشرية" (8 بطاقات + اختصارات)
  - 10 Print Formats (قوالب طباعة عربية RTL)
  - 2 Notification (إشعارات إجازة / مصروفات)
  - ~30 Translation (ترجمات عربية/إنجليزية)

كل دوال الإنشاء idempotent: إذا كان العنصر موجوداً تتخطاه ولا تكرره.

--------------------------------------------------------------------------
2) أمر تفعيل (إعادة إنشاء) البيانات الافتراضية
--------------------------------------------------------------------------
لتشغيل after_install يدوياً في أي وقت (لإعادة إنشاء البيانات أو بعد
حذفها):

        cd /home/newsmart/frappe-bench2
        bench --site site1.local execute hr_erp.hrms_erp.install.after_install
        bench --site site1.local clear-cache

تنبيه هام:
  - مساحة العمل "بوابة الموارد البشرية" تُحذف وتُعاد بناؤها بالشكل
    الافتراضي في كل تشغيل (لذلك أي تعديل يدوي على البوابة يُفقد).
  - باقي العناصر تُتخطى إذا كانت موجودة بالفعل.

--------------------------------------------------------------------------
3) أمر إزالة البيانات الافتراضية
--------------------------------------------------------------------------
لحذف كل ما أنشأه التطبيق:

        cd /home/newsmart/frappe-bench2
        bench --site site1.local execute hr_erp.hrms_erp.install.remove_default_data

يحذف:
  - Number Cards و Dashboard Charts و Print Formats و Notifications
    و Translations (التي module = hrms-erp)
  - مساحة العمل "بوابة الموارد البشرية"
  - الحقول المخصصة السبعة

ملاحظات:
  - لا يحذف DocType "Employee Document" ولا جدوله؛ لإزالة الجدول استخدم:
        bench --site site1.local uninstall-app hr_erp
  - النسخ الاحتياطي قبل أي إزالة:
        bench --site site1.local backup

--------------------------------------------------------------------------
4) التثبيت الكامل على سيرفر ثانٍ (من الصفر)
--------------------------------------------------------------------------
        cd /home/newsmart/frappe-bench2
        bench get-app hr_erp <مسار-النسخة-أو-git>
        bench --site site1.local install-app hr_erp
        bench --site site1.local migrate
        bench --site site1.local clear-cache
        bench build

بعد هذه الخطوات تكون البيانات الافتراضية جاهزة (النقطة 1).
