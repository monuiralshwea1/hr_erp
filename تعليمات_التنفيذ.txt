┌─────────────────────────────────────────────────────────────────┐
│ 1) ما الجديد في هذا التحديث                                     │
└─────────────────────────────────────────────────────────────────┘

• ضريبة الدخل 15% على موظفي شركة الشاحذي:
    - مكوّن جديد: «ضريبة الدخل» (اختصار TAX) — نوع: استقطاع
    - المعادلة: (BAS + TRN + RISK + NAT + HOU) * 0.15
      أي 15% من مجموع: الأساسي + المواصلات + المخاطر + طبيعة العمل + السكن
    - تُطبق تلقائياً على كل كشوف الرواتب (344 كشف)

• الأرقام المعتمدة:
    - إجمالي الاستحقاقات : 42,803,133 ريال يمني
    - إجمالي الضريبة     :  6,420,470 ريال يمني
    - الصافي المدفوع     : 36,382,663 ريال يمني

• تقرير shahadhi_full_report.xlsx (10 أوراق):
    أهم ورقة: «كشوف الرواتب» — لكل موظف ولكل شهر:
    الأساسي + البدلات الخمسة + إجمالي الاستحقاق + الضريبة 15%
    + إجمالي الخصومات + الصافي، مع صف الإجمالي في الأسفل.

┌─────────────────────────────────────────────────────────────────┐
│ 2) تنزيل التحديثات وتشغيلها                                      │
└─────────────────────────────────────────────────────────────────┘

■ الحالة أ: تحديث التطبيق الموجود أصلاً على سيرفر

    # اتصل بالسيرفر:
    ssh newsmart@newsmart

    # ادخل مجلد التطبيق:
    cd ~/frappe-bench2/apps/hr_erp

    # نزّل آخر التحديثات:
    git fetch origin
    git reset --hard origin/main

    # طبّق على قاعدة البيانات:
    cd ~/frappe-bench2
    bench --site site1.local migrate
    bench --site site1.local clear-cache
    bench restart

■ الحالة ب: تشغيل بيانات الشاحذي على أي موقع (حتى الجديد الفارغ)

    # من داخل مجلد البينش مباشرة:
    cd ~/frappe-bench2
    env/bin/python apps/hr_erp/shahadhi_full_seed.py site1.local

    ⚠ استبدل site1.local باسم موقعك المستهدف
    ⚠ مدة التنفيذ 4-5 دقائق — ينشئ كل شيء تلقائياً:
      الشركة، الحسابات، الأقسام، الموظفين (45)، هياكل الرواتب
      (مع الضريبة)، الحضور (440)، القيود (8)، الكشوف (344)

    إن كانت شركة الشاحذي موجودة مسبقاً في ذلك الموقع فسيكتشفها
    ويعيد استخدامها تلقائياً دون تكرار.

■ إنشاء موقع جديد كامل ثم تشغيل البيانات عليه:

    cd ~/frappe-bench2
    bench new-site shahadhi.local \
        --admin-password admin \
        --mariadb-root-password <كلمة-سر-MariaDB> \
        --install-app erpnext \
        --install-app hrms
    env/bin/python apps/hr_erp/shahadhi_full_seed.py shahadhi.local

┌─────────────────────────────────────────────────────────────────┐
│ 4) مثال حساب الضريبة                                             │
└─────────────────────────────────────────────────────────────────┘

موظف أساسي راتبه 70,000:
    الراتب الأساسي      BAS  =  70,000
    بدل مواصلات 20%     TRN  =  14,000
    بدل مخاطر 50%       RISK =  35,000
    بدل طبيعه عمل 60%   NAT  =  42,000
    بدل سكن 15%         HOU  =  10,500
    ──────────────────────────────────
    إجمالي الاستحقاق         = 171,500
    ضريبة الدخل 15%          = (25,725)
    ──────────────────────────────────
    الصافي                   = 145,775

الاستحقاقات مرتبطة بأيام العمل الفعلية — أي غياب يقلّص البدلات
وتُحسب الضريبة تلقائياً 15% من المستحق الفعلي.

للتعديل مستقبلاً: HR > Payroll > Salary Structure
→ SH-هيكل رواتب الشاحذي → تبويب Deductions → ضريبة الدخل
