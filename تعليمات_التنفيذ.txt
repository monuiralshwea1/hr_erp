• إضافة ضريبة الدخل 15% على موظفي شركة الشاحذي:
    - مكوّن جديد: «ضريبة الدخل» (اختصار TAX) — نوع: استقطاع
    - المعادلة: (BAS + TRN + RISK + NAT + HOU) * 0.15
      أي 15% من مجموع: الراتب الأساسي + بدل المواصلات + بدل المخاطر
      + بدل طبيعة العمل + بدل السكن
    - تُطبق تلقائياً على كل كشوف الرواتب (344 كشف)

• الأرقام المعتمدة الجديدة:
    - إجمالي الاستحقاقات : 42,803,133 ريال يمني
    - إجمالي الضريبة     :  6,420,470 ريال يمني
    - الصافي المدفوع     : 36,382,663 ريال يمني

• تحديث التقرير shahadhi_full_report.xlsx (10 أوراق):
    1. الموظفين          — بيانات الموظفين الـ45
    2. الأقسام والفروع    — إحصائيات الأقسام والفروع
    3. الرواتب والبدلات   — الراتب الشهري لكل موظف مع الضريبة والصافي
    4. فترات الدوام       — أنواع الدوام وفتراته واستراحاته
    5. ملخص الحضور        — حضور/غياب/ساعات/تأخير لكل موظف
    6. تفاصيل الفترات     — تفصيل كل فترة دوام بحالة وساعات وتأخير
    7. ملخص الفترات       — إجماليات حالات الفترات
    8. كشوف الرواتب ★     — التقرير الكامل: الأساسي + البدلات الخمسة
                            + إجمالي الاستحقاق + الضريبة + الخصومات + الصافي
                            لكل موظف ولكل شهر (344 كشف) مع صف الإجمالي
    9. قيود الرواتب       — القيود الثمانية مع إجمالي الصافي المدفوع
   10. ملخص شهري          — إجماليات كل شهر: استحقاقات/ضريبة/صافي

المتطلبات المسبقة على السيرفر الثاني:
    - Frappe Framework v15 + ERPNext v15 + HRMS v15 مثبتة عبر bench
      (راجع: https://docs.frappe.io/framework/user/en/installation)

خطوات التنفيذ:

    # 1. نزّل الملفين (أحد الطريقين):
    git clone https://github.com/monuiralshwea1/hr_erp.git
    # أو نزّل الملفين مباشرة من صفحة المستودع:
    #   shahadhi_full_seed.py   (السكربت — البيانات مدمجة بداخله بالكامل)
    #   shahadhi_full_report.xlsx (التقرير للعرض فقط — لا يُستخدم في التنفيذ)

    # 2. أنشئ موقعاً جديداً (إن لم يكن موجوداً):
    cd /home/<user>/<مجلد-البينش>
    bench new-site <اسم-الموقع> \
        --admin-password admin \
        --mariadb-root-password <كلمة-سر-قاعدة-البيانات> \
        --install-app erpnext \
        --install-app hrms

    # 3. شغّل السكربت من داخل مجلد البينش:
    cd /home/<user>/<مجلد-البينش>
    env/bin/python /home/<user>/hr_erp/shahadhi_full_seed.py <اسم-الموقع>

    ⚠ مهم: نفّذ الأمر من داخل مجلد البينش نفسه (حيث يوجد مجلد sites)
      حتى يجد السكربت المسار الصحيح تلقائياً.

ماذا يفعل السكربت؟ (كل شيء تلقائياً، مدته 4-5 دقائق)
    [1] إنشاء DocTypes المخصصة (فترات الدوام والحضور)

    [5] مكونات الرواتب (5 استحقاقات + الضريبة)
    [6] هيكل الرواتب SH-هيكل رواتب الشاحذي (مع الضريبة 15%)
    [7] 45 موظفاً بأرقام SH-HR-EMP-xxxxx
    [8] 45 تعيين راتب
    [9] 10 أنواع دوام + 45 تعيين دوام

┌─────────────────────────────────────────────────────────────────┐
│ 4) إذا كانت شركة الشاحذي منشأة مسبقاً في النظام                   │
└─────────────────────────────────────────────────────────────────┘

• السكربت يكتشف الشركة الموجودة تلقائياً ويعيد استخدامها
  ويضيف البيانات (الموظفين، الرواتب، الحضور...) دون المساس بما سوى ذلك.

• ⚠ حالة واحدة تحتاج انتباهاً: إذا كانت هناك بيانات قديمة على ذلك
  النظام من تشغيلة سابقة (نسخة بدون ضريبة)، فالهيكل الحالي لن
  يتحدث تلقائياً لأن السكربت لا يعدل على المستندات المرسلة.
  الحلول:
    أ) الأفضل: نظام نظيف (موقع جديد) ثم تشغيل السكربت
    ب) أو حذف بيانات الرواتب القديمة (كشوف + قيود + تعيينات + هيكل)
       ثم إعادة تشغيل السكربت

┌─────────────────────────────────────────────────────────────────┐
│ 5) تفاصيل الضريبة (للمرجعية)                                     │
└─────────────────────────────────────────────────────────────────┘

مثال حساب موظف راتبه الأساسي 70,000:
    الراتب الأساسي      BAS =  70,000
    بدل مواصلات 20%     TRN =  14,000
    بدل مخاطر 50%       RISK = 35,000
    بدل طبيعه عمل 60%   NAT =  42,000
    بدل سكن 15%         HOU =  10,500
    ─────────────────────────────────
    إجمالي الاستحقاق         = 171,500
    ضريبة الدخل 15%          = (25,725)
    ─────────────────────────────────
    الصافي                   = 145,775

ملاحظة تقنية: الاستحقاقات مرتبطة بأيام العمل الفعلية (Depends on
Payment Days) فإذا غاب الموظف تتغير الاستحقاقات وتتغير الضريبة
تلقائياً بنسبة 15% من المستحق الفعلي.

للتعديل مستقبلاً: HR > Payroll > Salary Structure
→ SH-هيكل رواتب الشاحذي → تبويب Deductions → ضريبة الدخل
