┌─────────────────────────────────────────────────────────────────┐
│ 1) الرفع من التطبيق (السيرفر المحلي) إلى GitHub                  │
└─────────────────────────────────────────────────────────────────┘

الاتصال بالسيرفر المحلي عبر SSH ثم:

    cd /home/newsmart/frappe-bench2/apps/hr_erp

    # مراجعة الجاهزية:
    git status
    git log --oneline -5

    # الدفع إلى الفرع الرئيسي main:
    git push origin master:main

    ⚠ عند الطلب سيظهر:
        Username for 'https://github.com': monuiralshwea1
        Password for 'https://...':  ← الصق هنا Personal Access Token
                                       (وليس كلمة سر حساب GitHub)

كيف أحصل على Personal Access Token؟ (مرة واحدة فقط)
    1. ادخل github.com بحسابك
    2. اضغط صورتك → Settings → Developer settings
       (أو الرابط المباشر: https://github.com/settings/tokens)
    3. Personal access tokens → Tokens (classic) → Generate new token
    4. الاسم أي شيء، الصلاحيات: علّم على repo فقط
    5. Generate → انسخ التوكن فوراً (لن يظهر مرة أخرى)

أمر بديل يحفظ التوكن فلا يسألك كل مرة (اختياري):

    git config credential.helper store
    git push origin master:main
    (أدخل المستخدم والتوكن مرة واحدة وسيُحفظ في ~/.git-credentials)

ما الذي يُرفع حالياً؟ (جاهز في المستودع المحلي على السيرفر)
    - cec1846  تحديث مساحة عمل بوابة الموارد البشرية + مولّد البيانات
    - 2289e84  ضريبة الدخل 15% + تقرير كشف الرواتب الكامل + دليل النشر
    - (وأي commit إضافي مثل هذا الملف)

┌─────────────────────────────────────────────────────────────────┐
│ 2) تنزيل التحديثات على سيرفر آخر — التطبيق مثبت مسبقاً            │
└─────────────────────────────────────────────────────────────────┘

على السيرفر الآخر:

    cd /home/<user>/<bench>/apps/hr_erp

    # إن كانت هناك تعديلات محلية لا تريد فقدانها:
    git stash

    # تنزيل آخر نسخة:
    git fetch origin
    git checkout master        # أو الفرع الذي تعمل عليه
    git reset --hard origin/main

    # تطبيق التغييرات على قاعدة البيانات:
    cd /home/<user>/<bench>
    bench --site <اسم-الموقع> migrate
    bench --site <اسم-الموقع> clear-cache

    # إعادة التشغيل:
    bench restart
    # أو إذا تستخدم supervisor:
    sudo supervisorctl restart all

┌─────────────────────────────────────────────────────────────────┐
│ 3) سيرفر جديد تماماً — تنزيل التطبيق لأول مرة                      │
└─────────────────────────────────────────────────────────────────┘

المتطلبات: Frappe v15 + ERPNext v15 + HRMS v15 مثبتة عبر bench

    cd /home/<user>/<bench>

    # تنزيل التطبيق من GitHub:
    bench get-app https://github.com/monuiralshwea1/hr_erp.git

    # تركيبه على الموقع:
    bench --site <اسم-الموقع> install-app hr_erp
    bench --site <اسم-الموقع> migrate

    # رفع بيانات شركة الشاحذي (45 موظف + رواتب + حضور + 344 كشف راتب):
    env/bin/python /home/<user>/<bench>/apps/hr_erp/shahadhi_full_seed.py <اسم-الموقع>

    ⚠ نفّذ الأمر الأخير من داخل مجلد البينش نفسه.
    ⚠ مدة التنفيذ 4-5 دقائق وتُنشئ كل شيء تلقائياً حتى لو كان
      النظام فارغاً (تنشئ الشركة والحسابات أيضاً إن لم تكن موجودة).

النتيجة المتوقعة نهاية التشغيل:
    Employee: 45 | SSA: 45 | Shift Type: 10 | Shift Assignment: 45
    Attendance: 440 | Payroll Entry: 8 | Salary Slip: 344
    إجمالي صافي المرتبات: 36,382,663 YER (بعد خصم الضريبة 15%)
